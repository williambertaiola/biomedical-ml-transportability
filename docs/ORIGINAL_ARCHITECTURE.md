# Original project architecture

The archive contains 18,318 ZIP entries and 9,432,805,399 uncompressed bytes, including macOS resource-fork metadata. After excluding directories and macOS metadata, there are 8,344 substantive files. There are 495 Python files, 255 byte-distinct Python contents, three R scripts, two RMarkdown report templates, two shell launchers, and no notebooks. A nested UCI SHAP ZIP contains a source script identical to its unpacked counterpart; its CRC also passed.

Top-level project groups:

| Original group | Role |
| --- | --- |
| `1_Data` | Preprocessing code, configs, intermediate and processed subject tables |
| `2_Codes_pipeline/1_Principal_scripts` | Selected standalone Python/R implementations |
| `2_Codes_pipeline/2_Codes_and_outputs` | Working implementations mixed with output snapshots and delivery copies |
| `3_Results_databases` | Dataset-specific organized M0–M4 packages, repeated runs and analysis scripts |
| `4_Comparative_analysis_tables` | Cross-dataset method/metadata discussion code and generated tables |
| `5_Figures` | Exported figures |
| `6_Other_reports` | Output inventory/report-generation script and generated reports |
| `Thesis_Bertaiola.pdf` | Thesis manuscript, excluded from publication copy |

Dependencies are dataset-specific preprocessing → processed CSV/schema → models and method adaptation → split/metric/prediction outputs → repeated-run aggregation and post-experiment reports. Standalone and modular generations are not interchangeable. Many output folders contain snapshots of the code that produced them. Byte identity was checked before redirecting those snapshots, rather than using filenames alone.
